# 规则包版本管理

热线分级判定的全部事实口径、危险信号、建议等级、纠正话术与分析参数都在规则包内，代码不内置医学结论。

## 文件与版本

- `pack-<语义版本>.json`：一份不可变的规则快照。发布后**不得修改**，任何调整都新增文件并提升版本号。
- 版本号采用 `主版本.次版本.补丁`：
  - 主版本：分级口径或危险信号集合变化（可能改变居民得到的建议）；
  - 次版本：新增规则/话术但既有判定不变；
  - 补丁：错别字、理由措辞等不改变判定结果的修订。
- 服务启动时用 `--rules` 指定规则包（默认加载 `rules/` 下版本号最大者），并在 `/health` 中回显当前版本。

## 调整流程

1. 复制上一版为新文件，修改后自检：枚举必须与仓库根目录 `domain.json` 的分类一致。
2. `python3 service.py --check` 校验规则包结构、枚举引用与优先级完整性。
3. 评审通过后发布；历史事件保留其当时响应记录中的规则版本与事实快照，可随时复算复核。
4. 每条自动回复都记录 `规则版本`、命中的规则 ID 与当时事实；规则包之间不做静默迁移。

## 边界

- 资料不足或事实矛盾时，规则包固定输出 `人工复核`，任何规则调整都不得删除该兜底。
- 规则包只描述处置分级与话术，诊断结论只能由线下或人工坐席作出。
